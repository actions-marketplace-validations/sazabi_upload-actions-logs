# upload-actions-logs

A GitHub Action that sends GitHub Actions job logs, plus one summary record per run, job and step, to [Sazabi](https://sazabi.com) as OpenTelemetry log records. Docs: [docs.sazabi.com](https://docs.sazabi.com).

## About

This is a release mirror. The action is developed in the private Sazabi monorepo; each release lands here as the exact content published under a version tag. Do not commit directly — content is published here by a maintainer-dispatched release run and direct commits will be overwritten on the next release.
